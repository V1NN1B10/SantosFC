# ⚪⚫ Santos FC — Página Web

Projeto desenvolvido para praticar os fundamentos de **HTML5 e CSS3**, criando uma página web dedicada à história e à tradição do Santos Futebol Clube.

## 📌 Sobre o projeto

A página apresenta informações sobre a história do Santos FC, imagens do clube, links relacionados à torcida e à história do time, além de uma seção com listas e um formulário de contato.

## 🚀 Funcionalidades

- Apresentação da história do Santos FC.
- Exibição de imagens e escudos do clube.
- Links para vídeos relacionados ao Santos.
- Acesso ao Instagram oficial e ao site do clube.
- Listas com informações relacionadas ao time.
- Formulário com campos de e-mail e senha.
- Efeitos visuais nos links e botões utilizando CSS.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação do conteúdo.
- **CSS3** — estilização, cores, espaçamentos, bordas, alinhamentos e efeitos de interação.

## 🎯 Objetivo

Praticar os conceitos fundamentais de desenvolvimento web, incluindo estrutura HTML, estilização com CSS, links, imagens, listas, formulários e efeitos de interação.

## 📚 Aprendizados

Durante o desenvolvimento, pratiquei:

- Estrutura básica de um documento HTML.
- Seletores e propriedades CSS.
- Uso de margens, espaçamentos e bordas.
- Centralização e alinhamento de elementos.
- Pseudoclasse `:hover` e propriedade `transform`.
- Criação de formulários e organização de conteúdo.
